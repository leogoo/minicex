二、整体思考（先理解，再敲）

  • 为什么用 Gin？ 它就是一个「路由 + 中间件」的 Web 框架，和你在前端用过的 Express / Koa 心智几乎一致。本课先把「HTTP 服务能起来」这关过了，后面所有模块（账户、撮合、充值）都挂在这个服务上。
  • 前端类比（务必记住，后面反复用）：
    Go / Gin前端等价物
    gin.EngineKoa app / Express app
    r.GET("/x", h)app.get('/x', h)
    gin.Contextctx（req+res 合一）
    middlewareKoa middleware（后续放 JWT 鉴权）
    r.Run()app.listen()
  • main.go 应该很小。 本课为了跑通先平铺，但从下一课起我们会把代码拆进 internal/ 按职责分层（这是 Go 项目的标准做法，也是你简历上「会组织后端工程」的体现）。

四、引导敲码（你来做，我给路径+提示）

步骤 1 · 建项目目录

在终端执行（这就是课程根下的项目目录）：

mkdir -p ~/Documents/leo/minicex/project
cd ~/Documents/leo/minicex/project

目标： 终端当前目录停在 project/ 里。

步骤 2 · 初始化 Go module

仍在 project/ 目录：

go mod init minicex

提示： minicex 是模块名，相当于这个项目的「包名前缀」。执行后会生成 go.mod。

校验： ls 能看到 go.mod。

步骤 3 · 引入 Gin 依赖
go get github.com/gin-gonic/gin

提示： 这一步会联网拉 Gin 并写进 go.mod 和新建 go.sum（依赖锁）。若你的环境有 Go 版本要求，留意终端报错——Go 1.16+ 都用这条。

步骤 4 · 写 Documents/leo/minicex/project/main.go

目标： 一个 Gin 服务，监听 :8080，响应 GET /ping 返回 JSON {"message":"pong"}。

提示（不要直接抄，先想每行在干嘛）：

package main

import "github.com/gin-gonic/gin"

func main() {
    r := gin.Default()           // 1) 创建一个引擎（≈ Koa app）
    r.GET("/ping", func(c *gin.Context) {
        c.JSON(200, gin.H{"message": "pong"}) // 2) 返回 JSON
    })
    r.Run(":8080")              // 3) 启动并监听 8080
}

关键片段拆解：

  • gin.Default() 带默认日志/恢复中间件，先用着；
  • gin.H{...} 是 map[string]interface{} 的简写，专门给 JSON 用；
  • c.JSON(code, obj) 同时设了 Content-Type 和状态码——和前端 res.json() 一个意思。

红灯提醒：本技能约定「不堆大块代码」。上面这段是本课唯一的手写文件，且是 hello-world 量级，所以完整给出——但你要自己敲一遍，每敲一行想清楚它在图里对应哪一块。

步骤 5 · 运行
go run main.go

提示： 终端应打印 Listening and serving HTTP on :8080。它阻塞在前台，别关。

五、跑通校验

另开一个终端，打请求（或用浏览器开 http://localhost:8080/ping）：

curl http://localhost:8080/ping

预期返回：

{"message":"pong"}
看到这段 JSON，本课满分通过 ✅。你现在已经有了「交易所后端」的第一个进程——后续所有模块都挂在这个 Gin 服务上。

六、生产 reality（⚠️ 可选，先不深究）

真实交易所的后端比这复杂得多，但你现在不用管，知道有这些坑即可，等 Phase 0–8 跑通后再说：

本课最简生产环境实际做法
r.Run() 前台阻塞用 http.Server + Shutdown() 做优雅退出，收到信号先处理完在途请求
单进程平铺REST/WS 网关 + 内部 gRPC 微服务（账户/撮合/清算分服务）
无配置配置走 viper（环境变量 / 文件），端口、DB、链 RPC 都外部化
无日志结构化日志 slog / zap，关键动作全留痕（风控审计要）

这些属于「生产扩展 C 阶段」范畴。本课只求跑通，别被它们带偏。
